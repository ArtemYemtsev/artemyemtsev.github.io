Проведи аудит модульного контента и навигации. Ничего не меняй без подтверждения — сначала собери отчёт.

Проверки:
1. **type ↔ componentsMap.** Собери все значения `type` из всех `content/**/*.json` (`body[].type`). Сверь с ключами `componentsMap` в @app/blocks/componentsMap.ts. Выведи: незарегистрированные `type` (блок не отрендерится) и зарегистрированные, но нигде не используемые компоненты.
2. **Типы полей.** Найди в `content/**/*.json` поля `draft`/`order`, записанные строками (`"true"`, `"2"`). Они должны быть `boolean`/`number`. Перечисли файлы и значения.
3. **Иконки спрайта.** Собери все `icon`/`xlink:href` ссылки вида `#<id>` из JSON и компонентов. Сверь с id, реально присутствующими в @public/sprite.svg. Выведи недостающие.
4. **Props ↔ JSON.** Для каждого используемого блока сверь ключи в JSON с `defineProps` компонента — отметь поля, которые передаются, но не объявлены (или объявлены, но всегда пустые).

Выведи итог таблицей с приоритетами (🔴 ломает рендер / 🟡 деградация / 🟢 косметика) и предложи, что починить.
